# Emerald Group Bot V2

ربات فارسی مدیریت گروه تلگرام با سیستم XP و لول، فروشگاه اختصاصی هر گروه، کلکسیون محصولات، مأموریت‌های قابل تنظیم و پنل مدیریت توسعه‌یافته.

## قابلیت‌های V2
- فروشگاه جداگانه برای هر گروه با محصولات لقب، نشان و قاب پروفایل.
- خرید امن XP با تراکنش دیتابیس؛ جلوگیری از خرید تکراری و خرید بدون موجودی کافی.
- کلکسیون هر عضو و امکان فعال‌سازی محصول خریداری‌شده در پروفایل.
- ثبت خرید و موجودی باقی‌مانده؛ داشبورد تعداد اعضا، مجموع XP، فعالیت اخیر و خریدها.
- لول‌بندی مستقل هر گروه با حالت آسان، استاندارد و سخت، به‌علاوه هزینه XP سفارشی برای لول‌های مشخص.
- مأموریت‌های XP روزانه، XP هفتگی و تعداد پیام روزانه؛ هدف و پاداش هرکدام از پنل قابل تنظیم است.
- مدیریت قیمت و فعال/غیرفعال‌کردن محصولات از پنل گروه.
- مهاجرت افزایشی SQLite؛ کد برای افزودن ستون‌ها و جدول‌های جدید طراحی شده و دیتابیس نمونه در این بسته قرار نگرفته است.

## پیش‌نیازها
- Python 3.10 یا جدیدتر
- بات تلگرام ساخته‌شده با BotFather
- اتصال پایدار سرور به Telegram Bot API

## نصب در لینوکس
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
nano .env
python bot.py
```

## نصب در ویندوز PowerShell
```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
notepad .env
python bot.py
```

اگر PowerShell جلوی فعال‌سازی محیط مجازی را گرفت، فقط برای پنجره فعلی:
```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
.\.venv\Scripts\Activate.ps1
```

## تنظیمات `.env`
- `BOT_TOKEN`: توکن بات از BotFather
- `OWNER_ID`: شناسه عددی تلگرام مدیر اصلی
- `DATABASE_PATH`: مسیر فایل SQLite؛ روی Railway باید مسیر Volume پایدار باشد، مانند `/data/group_bot.db`
- `XP_PER_MESSAGE`: مقدار پیش‌فرض XP هر پیام واجد شرایط
- `XP_COOLDOWN_SECONDS`: فاصله پیش‌فرض دریافت XP
- `ADMIN_LEVEL`: لول پیش‌فرض لازم برای درخواست ادمینی

تنظیم XP، سقف روزانه، حالت لول، هزینه لول‌های انتخابی، مأموریت‌ها و فروشگاه از پنل هر گروه مستقل است.

## فرمان‌های تلگرام
- `/start` و `/help`
- `/me` یا `/rank` — پروفایل
- `/top` — ۱۰ عضو برتر
- `/rewards` — راهنمای نشان‌های خودکار
- `/league` — لیگ مبتنی بر لول
- `/missions` — پیشرفت مأموریت XP روزانه/هفتگی و تعداد پیام روزانه
- `/achievements` — دستاوردهای دائمی
- `/shop` — فروشگاه گروه
- `/inventory` — کلکسیون و فعال‌سازی محصولات
- `/admin_request` — درخواست بررسی ادمینی
- `/admin` — پنل مدیریت در گفت‌وگوی خصوصی

## افزودن محصول از پنل
در `/admin` گروه را انتخاب کن و وارد «مدیریت فروشگاه» شو. افزودن محصول با قالب زیر است:

`نام محصول | نوع (لقب/نشان/قاب) | قیمت XP | قیمت امتیاز ویژه | ایموجی`

مثال: `لقب زمردی | لقب | 500 | 250 | 💚`
قیمت XP و امتیاز ویژه جداگانه قابل تنظیم هستند. قالب قدیمی چهارقسمتی هم برای قیمت یکسان پشتیبانی می‌شود.

نمونه: `لقب زمردی | لقب | 500 | 💚`

می‌توان قیمت را تغییر داد یا محصول را فعال/غیرفعال کرد. محصول غیرفعال برای خرید جدید نمایش داده نمی‌شود؛ خریدهای قبلی به‌عنوان مالکیت عضو باقی می‌مانند.

## سفارشی‌سازی لول
در تنظیمات گروه، «سیستم لول‌بندی» را باز کن و حالت آسان، استاندارد یا سخت را انتخاب کن. برای تعیین XP رسیدن به لول‌های خاص، «تعیین XP لول‌های مشخص» را بزن و مقادیر را به شکل `لول=XP` وارد کن؛ مثال:

`2=80 3=120 4=180 10=500`

عدد واردشده، XP لازم برای رسیدن از لول قبلی به همان لول است. فقط لول‌های واردشده سفارشی می‌شوند و بقیه از حالت انتخابی استفاده می‌کنند. پاک‌کردن این تنظیمات با نوشتن `پاک کردن` انجام می‌شود.

## نکات مهم انتشار و دیتابیس
1. قبل از انتشار هر نسخه، از فایل دیتابیس زنده بکاپ بگیر.
2. `data/group_bot.db` نمونه یا دیتابیس محلی را روی دیتابیس زنده کپی نکن.
3. روی Railway مقدار `DATABASE_PATH` را به مسیر Volume پایدار تنظیم کن و آن را به مسیر محلی تغییر نده.
4. ابتدا نسخه را روی شاخه/محیط آزمایشی تست کن؛ بعد از بررسی بکاپ و تست، نسخه زنده را به‌روزرسانی کن.
5. این بسته syntax-check و تست عملکرد دیتابیس/خرید را گذرانده، اما تست کامل زنده تلگرام و تمام مسیرهای UI هنوز باید در محیط آزمایشی انجام شود.
6. برای اینکه بات پیام‌های عادی گروه را ببیند، در صورت نیاز `/setprivacy` را در BotFather خاموش کن و بات را دوباره به گروه اضافه کن.

## محدودیت‌های فعلی
- حالت لول شامل سه پیش‌تنظیم و هزینه‌های سفارشی برای لول‌های مشخص است؛ برای هر سطح می‌توان هزینه رسیدن را جدا تعیین کرد.
- مأموریت‌های فعلی شامل XP روزانه/هفتگی و تعداد پیام روزانه‌اند؛ سازنده آزاد برای مأموریت‌هایی مثل فعالیت در چند روز یا رسیدن به لول خاص، هنوز پیاده‌سازی نشده است.
- قاب پروفایل فعلاً به‌صورت یک آیتم نمایشی در پروفایل ثبت می‌شود؛ ظاهر واقعی پیام تلگرام قابل رنگ‌آمیزی نیست.

### V2.0.3 — XP stays unchanged after shop purchases
Shop items still require the member to have at least the listed XP price, but buying an item no longer subtracts XP. XP remains a level score, so purchases cannot lower a member's level. Existing XP balances and the live SQLite database are preserved.
